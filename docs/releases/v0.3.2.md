# v0.3.2 · 5 GiB 视频与棋盘方向修复

- 单个 MP4 上传上限提高到 **5 GiB（5120 MiB）**，超过上限在传输前提示，后端保留独立校验。
- 原视频选择黑方在下后，虚拟棋盘、恢复标准开局、人工落子、移动标记、回放动画和导出录像遵循同一方向。棋子文字保持正向，红黑阵营不会因翻转而互换。
- 修复融合模型可能用另一阵营覆盖棋面字色的问题。原始模型评分保留；颜色冲突展示候选并要求核对保存，避免在自动初始化中直接确认。
- 保留红方在下、镜像、独立多窗口及本机数据保存方式。

下载 `XiangQi-Vedio-Reconstruction-0.3.2-win-x64-portable.exe` 后直接运行。任务仍保存在 EXE 相邻的 `data`，录像位于 `录屏存放`。如需接着处理原任务，将新版放在旧版相同目录；不要覆盖或删除数据目录。

模型仍可能留下棋种或占位疑点，需要人工核对。本版未签名，验证范围为本机 Windows x64，未在其他实体电脑验证。
