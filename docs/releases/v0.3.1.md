# v0.3.1：可单独运行的便携 EXE

发布日期：2026-10-25。

此前发布的是多文件 ZIP，内部 Electron 主 EXE 依赖同级 `icudtl.dat`、`resources` 等文件。只将内部 EXE 复制到桌面会在应用逻辑运行前退出，并产生 ICU 相关 debug.log。

本版新增 `XiangQi-Vedio-Reconstruction-0.3.1-win-x64-portable.exe`，单个下载文件包含完整运行环境、后台、界面、本地模型与许可。可直接放在桌面或其他可写目录运行，启动时自动展开运行文件并显示准备画面。无需安装 Python、Node.js、浏览器或配置云端 API。

每次启动使用独立临时目录，重复双击继续支持独立多窗口。个人任务和录屏保存在外部 EXE 相邻的 `data`、`录屏存放`，不会随临时运行目录清理而丢失。显式设置数据路径时保持原配置优先。内部数据锁重新分配实例时会通过外层 portable EXE 重启。

从旧版更新时，先关闭旧版，保留自己的 `data` 和 `录屏存放`，将新 portable EXE 放在这两个目录旁。旧 ZIP 的内部 EXE 仍不可单独复制，桌面入口应使用快捷方式。

识别、追踪、人工核对和导出规则未改变。已知识别边界仍见 [v0.3.0](v0.3.0.md)。构建未签名；支持范围以实际 Windows x64 启动、双开、持久化和下载验收记录为准，不承诺所有系统配置均兼容。

## 已完成的单文件验收

- 在只有单个 EXE 的独立中文空格目录启动，没有旁置 `icudtl.dat` 或 `resources`。
- 子进程 PATH 仅保留 Windows 系统目录；本地模型正常加载，并识别出32枚起始棋子。
- 两个窗口使用不同临时运行目录、后台与任务库；关闭窗口1清理自身运行文件后，窗口2仍健康。
- 再次启动复用窗口1的数据目录，读回之前保存的任务及初始识别结果。
- 桌面路径、重新启动和 Windows PowerShell 构建兼容性共11项测试通过。
