## 画质验收

用户已明确选择视觉质量与显著提速标准。逐像素比对仍作为诊断保留：728 张原始截图、1436 帧解码画面存在像素差异。

对全部 1500 帧计算原尺寸 RGB PSNR；整景灰度 SSIM 在 270×298 计算；从第 1 手起的 1440 帧，按实际移动轨迹跟随棋子，使用约 200×200 原尺寸局部计算 PSNR、SSIM 与边缘清晰度，并检查移动、吃子、落稳及最终局面。

| 检查 | 本次工程门槛 | 实测 |
|---|---:|---:|
| 整帧最低 PSNR | ≥48 dB | 49.6257 dB |
| 整段整体 PSNR | 记录实际值 | 53.2635 dB |
| 整景最低 SSIM | ≥0.999 | 0.99956918 |
| 棋子局部最低 PSNR | ≥38 dB | 39.3800 dB |
| 棋子局部最低 SSIM | ≥0.99 | 0.99095869 |
| 局部平均边缘清晰度比值 | 辅助记录 | 0.999871 |

门槛是本次工程检验条件，SSIM 不是“质量百分比”，这些数值也不是通用的人眼可见差异界线。第一次使用更保守的 50 dB/40 dB/局部 SSIM 0.995 门槛时未通过；随后结合用户确认的视觉标准与最差局部放大检查，确定上表门槛，重新运行验收。第 1330 帧局部 SSIM 最低，第 1466 帧整帧 PSNR 最低；已核对代表画面及最差局部，字体、边缘、阴影、光圈与移动外观未见可见质量下降。

结构相似度方法参考：[SSIM 原作者说明](https://ece.uwaterloo.ca/~z70wang/research/ssim/)。
