# 棋谱缺口修复与区域逐帧重检

用户已在本次对话确认设计并要求开始整改。目标版本为运行于 5288/8288 的融合识别实验版。

- 标题栏“对局步骤”与总手数之间放置“区域范围内重新检测”，没有步骤输入框或两个子按钮。
- 点击按钮后直接点选任意两条走棋记录，按原记录顺序确定边界；支持倒序点击、取消、重新选择。
- 严格范围：前边界 action_end_s 至后边界 action_start_s；旧记录缺少动作时间时明确提示核对，不将识别时间冒充动作时间。
- 两端保留，逐帧重建区间内部，纠错、补漏、去重。不用合法走法猜造无画面证据的步骤。
- 每次确认新落点更新局面；合并同手调整；保留遮挡、短暂变化、部分恢复及证据时间。末端画面核对与过程核对都必须通过。
- 结果先保存为候选，展示与已有走法及人工校正的差异，用户应用后原子替换区间。原记录留存用于恢复。
- 手动支持在当前步骤前插入，使用前一步结束局面及两步时间边界；保留单步替换及末尾追加。
- 替换/插入后重编索引、重映射关联步骤、保留区间外走法与人工编辑并重算后续局面，计数、定位、回放、导出一致。
- 重检进度在“对局录像”下方，与左侧视频扫描进度顶部横向对齐，不依赖聊天展示运行进度。
- 原任务验证只读；运行验证使用副本；不调用付费云服务，不接管其他服务端口。

验收：倒序选择、相邻边界找回两手、跨多步纠错去重、时间未知、遮挡未解决、停止/重启、并发版本保护、人工校正差异、保存后刷新与导出。
