# 多进程、计算复用与保存开销优化 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, then one independent review.

**Goal:** 按用户截图路线修改现有融合解析，对照真实整段耗时和完整输出；整段至少减半为验收目标，不将目标写成已达到。

**Architecture:** 保留解码输入、采样、阈值和串行棋局状态机。先测真实中后段历史负载，再以有界队列连接解码、独立画面进程和主线程；仅在逐像素等价时复用画面计算。保存优化保留事务、修订冲突、人工修订及恢复租约。

**Spec:** 本轮用户提供的四项路线截图及“按照这个路线更改一下，看对比度”的直接执行授权。

**Tech Stack:** 现有 Python 3.12、NumPy/OpenCV、Joblib/Numba、SQLite、融合模型；不更换模型。
