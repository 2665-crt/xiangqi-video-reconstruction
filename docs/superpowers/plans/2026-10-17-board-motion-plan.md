# 棋盘位移导致中途停步 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复 1.mp4 从0秒起分析在56.554秒后不再出步的问题，保持旧视频走法回归。

**Architecture:** 原视频约15～20秒棋盘发生整体位移，固定起始透视坐标失效。顺序解码时用局部特征和双向光流验证整盘变换，把每帧独立校准传入现有预处理；保留历史截图所属坐标，不改变人工校准与权重。

**Tech Stack:** Python / OpenCV / pytest，现有有界预处理流水线。

**Spec:** 当前对话已授权修复，疑点保留人工审核，后续继续自动出步，适用于不同视频。

## Global Constraints

- 不改活动模型、不按文件名或视频时间硬编码，不覆盖原任务和人工校正。
- 不放宽走棋证据；整体位移需要大量、分布充分且相互一致的背景特征。
- 没有足够证据时不移动坐标；保留当前有界回查与顺序状态确认。

## Review Focus

- 单枚棋子和手臂移动不能成为棋盘移动。
- 静止画面保持原始校准，避免噪声累计。

- 真实故障0～120/400秒越过56秒；旧片44步、15步走法保持。
