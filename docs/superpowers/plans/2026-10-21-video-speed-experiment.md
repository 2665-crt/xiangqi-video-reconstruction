# 视频解析等价提速实验实施计划

**Goal:** 在独立实验分支完善提速方案，正式版保持原状；等待用户命令再决定是否晋升。

**Architecture:** 全帧解码、原始时间戳、串行棋局状态机及证据处理保持不变。优先缓存相同参考画面的纯图像特征，并验证有界跨帧解码。静止检测只做对照诊断，不删帧、不替代走棋或推断状态更新。共享内存仅在确认传输瓶颈且证据生命周期可证明安全后再考虑。

**Tech Stack:** 现有 Python、PyAV、OpenCV、NumPy、pytest、React/Vite，无新增运行依赖。

**Baseline:** `467e3b5e5b5988eeaa494300134b56a9409e6c16`，从正式 main 的当前工作区复制，包括未提交源文件；280 个文件 SHA256 对照见 output/experiment-setup。模型、配置和依赖独立复制，14 个任务数据库快照一致；视频仅用只读硬链接复用。

## 边界

- 仅改 experiments/video-speed-experiment，正式 main 不切换、不合并、不推送。
- 不改变识别阈值、模型、分辨率、帧数、动作确认及 tentative 标记。
- 预取与缓存不改变棋局状态、推断采样、证据顺序和停止恢复。
- 专项测试使用中文实验目录；临时测试目录使用 Windows 扩展路径，规避深目录下 260 字符限制。
- 用户自行进行整片解析，本轮不发起长视频分析。
- 源码、模型和任务快照相同不等于共享可写文件：代码、证据、数据库及依赖均独立。
