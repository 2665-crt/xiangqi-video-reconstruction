# 视频提速实验版

实验目录：`F:\codex产出\虚拟棋盘对战录制\experiments\video-speed-experiment`

实验分支：`codex/video-speed-experiment`。初始一致快照：`467e3b5e5b5988eeaa494300134b56a9409e6c16`。正式目录仍在 main，未自动合并或晋升。

## 初始一致性与隔离

- 以当前正式工作区复制，包含正式版尚未提交的代码；280 个源文件、页面资源及文档逐项 SHA256 一致。
- 模型、配置及 Python/前端依赖独立复制；`.env` 只保存在本机且不会提交。
- 14 个正式任务的数据库快照保持一致，证据及恢复文件独立复制。源视频使用只读用途的硬链接，程序上传新视频时使用新任务目录，不覆盖已有视频。
- 旧实验、发布安装包、日志和进程 PID 文件不属于程序初始版本，不复制。重建缓存不计入源文件一致性。
- 正式端口 5278/8278；实验端口 5281/8281。实验数据、进程记录和日志均在本实验目录内。

## 已实施范围

- 缓存同一参考灰度图及掩膜对应的角点、SIFT 特征；参考图、坐标、掩膜尺寸或数据类型变化时失效。当前帧计算、镜头运动校准和所有时间状态继续执行。
- 全帧解码支持最多由配置指定的线程数，默认 4，保留原始像素格式、PTS、选区和尾帧。`VIDEO_DECODE_THREADS=0` 使用初始解码模式。
- `VIDEO_REFERENCE_CACHE=0` 关闭参考特征缓存，便于原设置对照。
- 新增诊断工具比较 Git 初始快照与实验代码的逐帧像素、时间戳及跟踪状态；活动变化只做诊断统计，不用于筛帧或确认走棋。
- 不改变棋子模型、阈值、走法规则、推断状态、回放、校正及录像导出。不引入共享内存，不采用每隔数秒跳帧。

## 启动与停止

在本实验目录运行：

```powershell
.\scripts\start-experiment.ps1
```

打开 `http://127.0.0.1:5281`。如需原设置对照，先停止，再运行：

```powershell
.\scripts\stop-experiment.ps1
.\scripts\start-experiment.ps1 -Baseline
```

停止只核验并处理本实验目录记录的进程；同一目录已运行时，禁止用另一组端口再启动并覆盖记录。原 `start.ps1`、`stop.ps1` 保持正式版原样，请使用本说明中的实验入口。

## 程序检查与性能对照

先在 PowerShell 配置本实验的依赖路径：

```powershell
$env:PYTHONPATH = "$PWD\.venv\Lib\site-packages;$PWD\backend"
$env:PYTHONIOENCODING = 'utf-8'
```

合成画面检查，不执行真实视频识别：

```powershell
& .\output\github-recognition-study\.venv\Scripts\python.exe .\scripts\validate-video-speed.py --synthetic --baseline-ref 467e3b5 --repeats 3
```

对本实验数据库中的某个任务检查指定片段：

```powershell
& .\output\github-recognition-study\.venv\Scripts\python.exe .\scripts\validate-video-speed.py --task-id '<任务ID>' --start 0 --duration 30 --baseline-ref 467e3b5 --repeats 3
```

片段检查只读取视频和任务，不执行走棋解析，不写任务数据库。输出在 `output/video-speed-validation/comparison.json`；它只能证明这段输入的解码与防抖输出等价，不能代替整片走棋准确率或完整解析速度验收。源文件目录较深时，pytest 临时目录需要使用 `\\?\` Windows 扩展路径。

本轮不自动运行完整真实视频解析，由用户自行验收；收到用户明确命令前保持实验版，不提升为正式版。
